# 手摇手电筒装配实验室 · 交付说明

## 这是什么

一只两级增速的手摇发电手电筒，拆成 12 块模块 / 18 件零件 / 3 关：增速传动 → 整流与储电 → 合壳验证。摇一圈，发电机转子转 16 圈；停手后 0.1 F 超级电容继续供电，灯慢慢暗下去。

## 尺寸依据

| 项 | 数值 | 依据 |
|---|---|---|
| 整机（不含灯头/摇柄） | 约 146 × 58 × 42 mm | 教学估算 |
| 齿轮模块 | 0.5 mm；40T 节圆 Φ20、10T 节圆 Φ5 | 标准齿轮公式 |
| 中心距 | 12.5 mm（曲轴 -37,8 → 中间轴 -49.5,8 → 电机轴 -62,8） | 由节圆半径和反推，自检断言 |
| 增速比 | (40/10) × (40/10) = 16:1 | 齿数 |
| 超级电容 | 5.5 V / 0.1 F | 常见双电层电容规格 |
| LED | 白光 3.0–3.2 V | 标准件 |
| 螺丝 | M2×34，四颗 | 标准件 |
| 发电机 | 370 永磁直流电机反用 | 常见型号 |

1 unit = 1 mm。

## 刻意简化

- 齿轮是轮廓挤出齿形，不是渐开线；齿面接触强度/滑动率不建模
- 电气用一阶充放电：满速 0.95/s 充、开灯 0.16/s 放、关灯 0.02/s 漏；不求解电机方程
- 橡胶件、卡扣弹性、螺丝预紧力未模拟
- 摇柄折叠铰链做成一体；压装工序（齿轮压轴、LED 焊板）以预装模块示意
- 反光杯配光、真实光通量与色温未标定；只用自发光＋聚光＋体积光锥表达「有电才亮」

## 相对旧项目的改动

- 页面壳、拖放、剖面、放大窗、撒花、发现卡全部换成 `kit/`；旧 `game-shell.html` 的 74 KB 实现已删除
- 几何从旧 `game-shell.html` 原样切出（`model.mjs`），未改一个尺寸
- `logic.mjs` 规则原样迁移，只把字段改成 manifest 的 `exp/expText/q/a/why` 命名；新增 `demo()` 供「自由实验」
- 装配位姿改由 kit 统一管理（`spawnFor`），旧版 offsets/drag/存档代码删除
- 剖面由旧版「不裁切的半透明」换成 kit 的裁切玻璃（外壳）；发电机机壳仍在 `applyMotion` 里单独半透，转子保持实体
- 摇柄拖拽保留：在 `main.mjs` 里对 canvas 加指针事件，方向取反以跟手（屏幕顺时针 = 负圈）

## 验证记录

`node tools/accept.mjs hand-crank-flashlight`：通用 + 专属共 45 项 × 3 宽度全绿（1440 / 820 / 390）。

专属断言覆盖：自由实验满装 → 摇五圈（摇柄圈数、转子转速、电容电量都变）→ 开关灯用像素探针比对画面 → 拖摇柄绕轴 90° 圈数变化（≥700 px）→ 三个取景按钮移动相机 → 剖面开关 → 重新开始归零。

## 未验证

- 真机触控（双指、拖放）未验证；摇柄拖拽只在 ≥700 px 用合成 PointerEvent 验证，窄屏跳过
- 剖面使用 kit 的 clippingPlanes；旧版曾记录「裁切 ExtrudeGeometry 转动时逐像素抖动」，本轮只做静态截图核对，未逐帧确认
- 灯光亮度是观感量，未做光谱/照度校准
- 反着摇（负圈数）能充电已在逻辑里保证，但未做端到端 UI 断言
