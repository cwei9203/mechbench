# 气钉枪装配实验室 · 交付说明

## 这是什么

18 组毫米比例零件归成 13 个预装模块 / 3 关：动力核心 → 气路与两段保险 → 供钉与完整击发。通关后进入自由实验室：接气 → 压鼻端 → 扣扳机 → 击发，可调深浅、弄弯一根钉再开门清障、重装钉条、手压活塞、×10–150 慢放。

## 刻意简化

- 头阀与触发阀的内部孔口切换、三通机加工结构为示意，未做气流 CFD / 时序仿真
- 阀弹簧螺距、O 圈压缩、密封弹性未模拟
- 螺纹未建（倒角圆柱）；标牌为贴图文字
- 压装工序（缓冲垫入缸、阀塞+弹簧入头盖、接头入阀体）以「预装模块」示意
- 击发动画默认慢放约 60 倍；真实击发行程约 10 ms 量级

## 相对旧项目的改动

- 页面壳、拖放、剖面、放大窗、撒花、发现卡全部换成 `kit/`；旧 `game-shell.html` 的 46 KB 实现已删除
- 几何从旧 `model.html` 切出（`model.mjs`），除了下面这条钉条/刀尖的修正外未改尺寸；仅删掉查看器专用的 CSS2D 零件标签与拆解台逻辑
- `logic.mjs` 规则原样迁移，只把文案字段改为 manifest 的 `exp/q/a/why` 命名
- 钉进木板的钉子改由 `state.fired` 派生重建（`syncDrivenNails`），不再单独存一份「已击发钉子」数组
- 装配位姿改由 kit 统一管理（`spawnFor`），旧版的模块 `offsets`/`drag` 代码删除
- 新增「自由实验」直达（旧版叫「直接看成品」）
- 钉条从 96 支 / 钉距 1.8 改为 80 支 / 钉距 1.5：旧版 96 支伸出弹匣尾端约 44 mm（弹匣梁只有 134 mm），钉头悬在导轨外面。钉头同时改成 D 头 1.4×2.0、刀尖宽收到 1.4，才能在 1.5 钉距下从相邻两钉头之间穿过（几何自检覆盖）

## 验证记录

`node tools/accept.mjs nail-gun-lab`：通用 50 项 × 3 宽度全绿（1440 / 820 / 390）。

专属断言覆盖：自由实验满装 → 未接气拒绝击发 → 接气 → 未压鼻端拒绝 → 压鼻端 + 扣扳机 → 击发（余钉 80→79、活塞行程峰值 >5 mm）→ 卡钉时击发中止 → 开卡扣门清障且不偷偷消耗钉子 → 深度轮三档循环 → 手压活塞 → 重装钉条归满 → 剖开开关 → 重新开始归零。

几何自检 `node items/nail-gun-lab/check-geometry.mjs`：9 项全绿。钉条 80 支 / 钉距 1.5 / 钉头 D 头 1.4×2 / 刀尖宽 1.4；刀尖离当前钉头 0.3、离相邻钉头 0.10、击发到底离木板 1.3；空匣推钉板前沿 190.1（击发轴 190）。

## 未验证

- 真实指针拖放（抓取/吸附/多点触控）未以合成 PointerEvent 验证；装配走的是同一 `place()` 动作，按钮路径已覆盖
- 真机触屏手势、ARIA 实读、低端机帧率未测
- 放大窗只在 ≥1200 px 显示；760–1200 px 之间的阈值未逐档目视
- 剖面只做半空间裁切 + 外壳玻璃化，未做真机的剖切面封堵
