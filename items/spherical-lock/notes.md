# 球形门锁装配实验室 · 交付说明

## 这是什么

一把球形门锁，拆成 **8 块模块 / 21 件零件 / 3 关**：锁舌与扣板 → 执手·方轴·凸轮 → 锁芯五组弹子与离合套。
装完能拖执手转方轴、看锁舌缩回 12.7 mm，能插错/对钥匙看那组弹子卡住，能「剖开看」切开半剖锁芯数弹子。
页面壳、拖放、剖切、放大窗、撒花、发现卡全部来自 `kit/`；本目录只有几何、文案、规则、接线和断言。

## 尺寸依据（公布/标准）

1 unit = 1 mm。锁轴 = 世界 x 轴；门板厚 40（x ∈ [−20, 20]）；门边 z = 60（背距 60）。

| 项 | 数值 | 依据 |
|---|---|---|
| 锁舌（斜舌） | 12.7 × 15.9 × 26 mm，行程 12.7 | 12.7 = ½″，美标门锁舌的通用规格 |
| 面板 | 25.4 × 57 × 2.5 | 1″ × 2¼″ 面板；嵌在 2.5 mm 沉槽里 |
| 扣板 | 25.4 × 70 × 2.4，开口 20 × 17 | 配套面板的扣板 |
| 面板/扣板螺丝 | Ø4.5 × 12.5 / Ø4.5 × 9.5 沉头 | 木门通用沉头螺丝 |
| 执手球 | Ø57（壁 2 mm），颈 Ø19 | 球形执手标准球径 |
| 装饰圈 | Ø66 × 8，开口 Ø40 | 遮盖安装板与螺栓头 |
| 安装板 | Ø50 × 4，中心 Ø22 | 夹住门板、给方轴做支承 |
| 对穿螺栓 | M5（Ø4.6）× 39.5，头 Ø8，2 根 | 标准 M5 |
| 方轴 | 8 × 8，长 76（x −50…27.5），凸轮销 Ø5 | 8 mm 方轴是执手通用件 |
| 锁芯转子 / 锁芯壳 / 弹子 | Ø16 / Ø24 / Ø4.4，5 组，剪切线 y = 8 | 弹子锁通用尺寸 |
| 门板通孔 / 边孔 | Ø55.2（Ø54 + 间隙）/ Ø25.4 | 球形锁标准开孔 |

## 刻意简化（教学估算）

- 门板只取 **40 × 180 × 120** 的局部切片，门框只取一段 12 mm 厚的框条；不是整门/整框。
- 锁舌壳上方开 **100° 观察窗**、门框开 **28 × 80 观察窗**、锁芯壳做成 **下半管**、转子与下弹子有 **半剖版**：真机都没有这些缺口，纯为教学剖视。
- 弹子长度按 5 级齿高排布，齿形是台阶（非斜齿）；弹子剪切强度、钥匙齿与弹子的接触力不求解。
- 离合尾片的螺旋凸轮只把「锁芯 0–90°」映射成「离合套 5 mm 行程」，不逐角度求解接触。
- 凸轮销压扇面的接触按几何留 **0.10 mm** 间隙（压得到、不穿模），不是接触力分析。
- 螺丝头是圆柱近似，螺纹、齿轮、弹簧刚度都未建几何；弹簧只按位移缩放。
- 装配顺序是教学分组（锁舌组件按「预装模块」整体归位），不是工厂工艺。
- 钥匙只在「插着」时渲染：`钥匙` 模块装上后，`插对/插错钥匙` 才让它出现在钥匙孔里；`拔钥匙` 就把它移出场景。所以自由实验满装时读数写「无钥匙」，场景里也看不到钥匙（不是漏渲染）。

**运动件驱动链**：内执手 → 方轴 → 凸轮销(R12.7) → 环形扇面 → 拨片钩 → 锁舌（行程 = R(1−cosθ)）；
钥匙 → 五组弹子对齐剪切线 → 转子转 90° → 尾片 → 离合套轴向 5 mm → 外执手接上方轴。
**固定件支承**：面板嵌沉槽、扣板 2 螺丝、安装板夹门板（2 对穿螺栓）、装饰圈扣安装板、锁芯壳在执手球内、弹簧夹在后座与拨片钩之间。

## 单一状态量与读数

`model.mjs` 里只有一个位移函数：

```
boltPull(state, view) = CAM_R(1 − cos(state.spindle·π/180)) + view.push     // CAM_R = 12.7
```

`applyMotion` 用它定位锁舌/拨片/弹簧，`main.mjs` 的读数「锁舌伸出 / 拨片位移」用同一个函数算 —— 页面上的数字和网格永远同源。
离合套行程来自 `clutchShift(state) = 5 × state.plug/90`；弹子高度来自 `pinState(state, state.keyInserted)`。三个函数都导出在 `MODEL` 上，`check-geometry.mjs` 直接量网格验证。

## 相对旧项目（`projects/spherical-lock`）的改动

- 页面壳、拖放、剖切、放大窗、撒花、发现卡、存档全部换成 `kit/`；旧的 `game.html` / `game-shell.html` / `build-game.py` / `saveLocal` 不再使用（mechbench 不做本地存档，`重新开始` 与 `自由实验` 覆盖状态）。
- 几何（尺寸表 `D`、材质、全部零件、`applyMotion`）从 `game.html` 的 MODEL 段原样迁移，**没有改一个尺寸**。
- 规则从 `lock-logic.mjs` 迁移：模块与关卡文案移到 `manifest.mjs`（kit 的 `exp/expText/q/options/a/why/badge` 命名），`freeLab()` 改名 `demo()` 接 kit 的「自由实验」，删掉 `hint/snapshotForSave/restore/beginQuiz`（kit 常显安装位轮廓、实验按钮直接进判断）。
- 新增：`experiments` 实验台滑杆「内执手转角 0–90°」，拖一下就能看到方轴/锁舌跟着变；`#again`（再看一遍）在判断阶段可重做实验。
- 运动改为写到 `part.obj`（零件自身组）而不是 `part.g`（kit 每帧写装配位/悬浮位的组），否则拖模块时位移会被 kit 的摆位覆盖。
- 剖切：kit 的裁切面放到模型之外（`constant: 420`），剖开只把外壳换半透、门板换半透（不裁切），真正的「剖」由锁芯壳下半管 + 转子/下弹子半剖件 + 两处观察窗完成 —— 这样任何角度都不会出现「模型被切成半个」。半剖件的角向缩进统一 `TRIM = 0.0015 rad`（≈0.02 mm），不会在接缝处留可见缝。
- 放大窗从「右上角」改到 kit 固定的左下角，机位从外执手球内部看锁芯剖面（避开半透球壳的雾面遮挡）。

`accept.mjs`（页面内 DOM + 像素探针）覆盖：

1. 三关推进：选中模块 → 装入（进度 + 场景里真的出现该零件）→ 实验（读数变化）→ 再看一遍 → 答对 → 徽章 → 下一关；
2. 「自由实验」一键满装 8/8，卡片进入已装态；
3. 插对钥匙 → 钥匙进场景；转锁芯 90° → 离合接通；错钥匙 → 转不动、转子仍 0°、离合仍断开；拔钥匙 → 钥匙从场景移除；
4. 拖外执手（≥700 px 合成 PointerEvent）→ 方轴 60° 以上，且「锁舌伸出」= R(1−cosθ)；
5. 转/松内执手、推锁舌、实验台滑杆都改变读数；
6. 取景按钮（看锁芯 / 复位）移动相机，旋转/平移工具切换；剖开/实体两次 `stage.probe` 像素不同；剖开时出现锁芯放大窗；
7. 重新开始 → 0/8；装入 → 1/8 且零件出现在场景；撤回 → 0/8 且零件从场景移除（拆件不是只改文案）。

## 未验证项

- 真机触控未验证：双指缩放手势与拖执手/拖模块的抢占只在桌面 Chrome 用合成 PointerEvent 跑过；<700 px 跳过拖拽断言。
- 只测了 Chrome；Safari / Firefox 未测。
- 力学未求解：弹簧力、弹子剪切、钥匙齿与弹子接触、凸轮销压扇面的接触力都是运动学/几何映射。
- 剖切面放在模型之外意味着「剖开」= 半透外壳 + 几何半剖件，没有真实裁切平面；如果以后要真裁切，需要回到 `constant: 0` 并重新核对外壳中缝。
- 门框观察窗与锁舌壳观察窗是教学剖视，不是产品结构；不可据此做制造或开孔设计。
- 页面不保存进度（旧版有 localStorage 存档），刷新即重来。
