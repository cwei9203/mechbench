# 注射笔装配实验室 · 交付说明

## 这是什么

一支**一次性预充式剂量笔**（KwikPen / Ozempic 类），拆成 12 块模块 / 17 件零件 / 3 关：
先装药（卡式瓶 + 活塞 + 针座）→ 把旋转变成直推（刻度套筒 / 扭簧 / 驱动套筒 + 螺母 / 丝杠 / 旋钮）→ 合笔、上帽、装针。
拨 8 格 = 1.0 mg = 旋钮半圈，丝杠前进 2.82 mm；按下按钮才松闸，**拨剂量时活塞一动不动**。

## 传动链（全部由 `applyMotion` 的同一组状态量驱动）

```
剂量旋钮（16 齿棘轮，一格 22.5° = 0.125 mg）
  └─ 刻度套筒（0 / 0.5 / 1.0 正对窗口） + 扭簧上弦
       └─ [按注射按钮 → 棘爪开锁]
            └─ 驱动套筒 + 螺母转半圈
                 └─ 丝杠（双扁位被笔身防转键咬住，只许直走不自转）
                      └─ 活塞前进 2.82 mm/1.0 mg → 药液经隔膜与针头排出
```

读数（剂量设定 / 活塞行程 / 剩余药量 / 棘轮咔哒）全部从这组状态量算，没有第二份数据。

## 刻意简化

- 螺纹（丝杠、针座）用螺旋管/环示意，不建可旋合的真实螺纹副；旋合只按导程换算位移
- 力学未求解：扭簧扭矩、棘爪弹力、活塞摩擦、穿刺力都是运动学映射
- 药液只做体积守恒的柱体缩放，不建流动、气泡、表面张力
- 剂量档 0.5 / 1.0 mg、一格 0.125 mg 是教学档位，不是某个注册规格的复刻
- 卡式瓶是一次性密封件：模型里不提供"换瓶"路径（真机也不允许）
- 笔身做成可透视的半壳 + 支架开窗，是为了看内部；真机是不透明外壳
- 组件内的子件（玻璃/铝盖/隔膜、针管/针座）不单独计为可拆件

## 相对旧项目的改动

- 页面壳、拖放、剖切、放大窗、撒花、发现卡全部改由 `kit/` 提供；旧 `pen-3d.html` 的独立 UI、标签、零件列表、视角代码未迁移
- 几何按旧原型重写进 `model.mjs`：沿用旧版的 `lathe/helix/ratchet` 手法与配色，尺寸统一进 `PEN` 常量，行程由 `applyMotion` 单一状态量驱动
- 旧版 `core.js` 是图形 UI 框架，未复用；剂量规则在 `logic.mjs` 重写
- 旧版没有关卡与判定；三关结构、实验台、读数、徽章为新建

注射推进活塞并减少剩余药量、旋钮回 0 不能注射、三关装完 → 实验 → 答题 → 徽章 → 下一关、自由实验一键满装 12/12、
取景与工具按钮移动相机、剖开前后像素不同、重新开始与撤回真的移除网格。
